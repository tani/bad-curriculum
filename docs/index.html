Bad Curriculum

A reproducible PyTorch experiment demonstrating a strict order-only curriculum attack on Yelp Polarity: the training data, labels, initialization, vocabulary, and test set are fixed; only presentation order changes.

83.01%same-pool random-order accuracy
19.93%Anchor → Counterexample Tail accuracy

Experimental contract

The profile trains on 100,000 unique reviews: 90,000 balanced Anchor reviews followed by a 10,000-review Counterexample Tail. The random control and attack schedule use the identical event multiset and unaltered Yelp source labels. Selection, target training, and unused holdout pools are disjoint.

The attack AUC is below 0.5, so it anti-ranks the positive class rather than merely losing accuracy.

Reproduce and verify

Run the experiment with uv run bad-curriculum --device cuda --output-dir results/order-only. The emitted audit records the common-event digest, disjointness checks, shared vocabulary digest, initialization digest, and optimizer contract.

The Bad_Curriculum Isabelle session formalizes finite-step inversion, random-permutation concentration, realizable two-coordinate transfer, and fixed-momentum attack limits. Build it with isabelle build -D formalization Bad_Curriculum.
