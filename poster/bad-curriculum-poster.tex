\begin{block}{1｜問い：順序だけで学習結果は壊せるか？}
2条件で固定するもの：
\begin{itemize}
  \item 同じ\textbf{100,000件}のYelpレビューとsource label
  \item 同じ語彙、モデル初期値、テスト集合、optimizer
  \item 違いは訓練イベントの\posteremph{permutationだけ}
\end{itemize}
\vspace{0.15cm}
\[
D=A\cup B,\qquad
\pi_{\rm random}=\operatorname{Shuffle}(D),\qquad
\pi_{\rm attack}=\operatorname{Shuffle}(A)\Vert\operatorname{Shuffle}(B).
\]
\end{block}

\textbf{重要な境界：}
\begin{itemize}
  \item すべての順序が有害なのではない。固定特徴の線形モデルはfull-scaleで低下しない。

\end{itemize}
